# 연습용 더미 자료 (가상 사건)

프로그램을 시험해 볼 수 있게 만든 **가상의 사건 서류**입니다. 인물, 금액, 번호는 모두 지어낸 것이고 실제 사건과 관계가 없습니다.

사건: 홍길동(가상)의 2023년 귀속 종합소득세 경정청구 거부처분 취소 청구 (합계 12쪽 안팎)

## 올리는 방법

메인 화면의 ① 서류에서 **구분을 맞춰** 올립니다. 증거서류는 올릴 때 증거 이름을 입력해야 합니다.

| 파일 | 올릴 칸 | 증거 이름 입력 | 비고 |
|------|---------|----------------|------|
| `01_청구이유서.pdf` | 청구이유서 | (없음) | 3쪽, 글자가 들어 있는 PDF |
| `02_답변서.pdf` | 답변서 | (없음) | 3쪽 |
| `03_갑제1호증_사업자등록증.pdf` | 청구인 증거서류 | `갑 제1호증` | 1쪽, 표 |
| `04_갑제2호증_임대차계약서.pdf` | 청구인 증거서류 | `갑 제2호증` | 2쪽, 표 |
| `06_갑제3호증_영수증_스캔.pdf` | 청구인 증거서류 | `갑 제3호증` | **스캔본(그림)**. 올린 뒤 [글자 인식 시작]을 눌러야 검색됩니다 |
| `05_을제1호증_결정서.pdf` | 처분청 증거서류 | `을 제1호증` | 2쪽, 표 |
| `07_갑제4호증_거래명세서.pdf` | 청구인 증거서류 | `갑 제4호증` | 2쪽, 표 (직접 올려 보기용) |

## 해 볼 것

- **검색:** `경정청구`, `필요경비`, `가산세`, `임차료`, `기한`, `납부지연가산세` 등으로 찾아 보고 [쪽 그림]으로 원본과 대조해 보세요.
- **스캔 쪽 검색:** 영수증을 글자 인식한 뒤 `영수증`, `책상`, `가나다오피스가구`로 찾아 보세요. 스캔 글자 인식은 완벽하지 않아서, 금액처럼 숫자가 섞인 글(예: `6,500,000`)은 못 찾을 수 있습니다. 이럴 때는 [쪽 그림]으로 원본을 보고 확인하는 연습을 해 보세요. 인식이 불확실한 글자는 점선 밑줄과 `[인식 불확실]`로 표시됩니다.
- **담기 규칙:** 청구이유서의 원문은 "청구인 주장"에만, 답변서의 원문은 "처분청 의견"에만, 증거서류의 원문은 "사실관계"에 담깁니다. 다른 항목에 담아 보면 막히는지 확인해 보세요.
- **초안:** 초안 화면에서 글을 수정해 보고(수정됨 표시), 원문으로 되돌려 보고, 워드·한글·증거 목록표로 저장해 보세요.
- **법령 조문 찾기:** 법령명 `국세기본법`, 조문 번호 `제45조의2`를 넣어 보세요. (법제처 연결이 필요합니다.)
- **유사 선결정례·판결:** 검색어 `경정청구 기한`으로 조세심판원 결정을 찾아 보세요.
- **중복 막기:** 같은 PDF를 다시 올리면 "이미 올린 파일입니다"로 막히는지 확인하세요.
- **사건 삭제:** 다 해 본 뒤 [사건 삭제]로 모두 지울 수 있습니다.
